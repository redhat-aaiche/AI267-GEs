2) CLI -- Get the owner hierarchy of workbench pod :
[developer]$  oc get pod
[developer]$ oc get pod/< pod name > -o jsonpath='{.metadata.ownerReferences}' | jq
[developer]$ oc get sts
[developer]$ oc get sts/< stateful set name > -o jsonpath='{.metadata.ownerReferences}' | jq
[developer]$  oc get notebook 
[developer]$  oc get notebook/< notebook name > -o jsonpath='{.spec}' | jq

3) CLI -- List the Openshift resources created for the workbench :
[developer]$  oc get pod,svc,sts,route


4) Dashboard -- Add addtional storage :
name : 			additional-storage

5) View the Openshift Resources created :
[developer]$  oc set volumes pod/< pod name >
